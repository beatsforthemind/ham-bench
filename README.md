# Ham Bench

Practice for the US amateur radio exams. The license is still earned in person with Volunteer Examiners. This app is the bench: the public-domain NCVEC pools, a mock that draws one question from each group, and labs for Ohm’s law, schematics, antennas, propagation, and safety.

Question wording and official figures come from the NCVEC releases. Explanations and labs are original. Progress stays in the browser.

```bash
pnpm install
pnpm dev
pnpm test
```

The app targets Node.js 24 or newer and deploys as a static-first Next.js site.
